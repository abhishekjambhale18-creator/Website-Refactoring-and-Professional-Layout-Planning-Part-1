---

### 📌 Project Overview
This lab expands the BiteBox website into a **complete multi-page structure**.  
All major pages (Home, Menu, About, Contact) now include rich content sections, images, and a professional layout ready for CSS styling.

---

### ✨ What Was Added

**Home Page (`index.html`)**
- Logo in header
- Hero section with Call-to-Action buttons
- Why Choose BiteBox (4 feature cards)
- Featured dishes with ratings & prices
- Special offer section
- Customer reviews
- Newsletter subscription
- Full professional footer

**About Page (`about.html`)**
- About hero section
- Our Story with image
- Mission & Vision
- Meet Our Chefs (3 chef profiles)
- Restaurant Statistics

**Menu Page (`menu.html`)**
- Menu hero section
- Browse Categories with icons
- Menu items with images, ratings, prices & Add to Cart buttons
- Special offer section

**Contact Page (`contact.html`)**
- Customer Registration & Order Form (from previous lab)

### 🛠️ Skills Demonstrated
- Multi-section page structure
- Semantic HTML (`header`, `nav`, `section`, `article`, `footer`)
- Image integration
- Content organization for real-world websites
- Professional footer design
- Preparing structure for CSS styling

---

### 🚀 How to Run
1. Open the repository
2. Open `index.html` in any web browser
3. Navigate between pages using the menu

> **Note:** Make sure all images are placed inside the `assets/images/` folder with correct relative paths.
